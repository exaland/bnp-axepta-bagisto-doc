# Attribut 

Dans cette option, vous pouvez facilement ajouter la taille d'une **image et d'un fichier** (en Ko) à partir d'ici pour améliorer le comportement, l'apparence ou la fonction. 

Pour ajouter, allez dans le panneau d'administration et cliquez sur **Configurer >> Produits >> Attribut** 

<ImagePopup src="/images/configure/attribute.png" alt="Attribute" /> 

Cliquez ensuite sur le bouton **Enregistrer la configuration**.
