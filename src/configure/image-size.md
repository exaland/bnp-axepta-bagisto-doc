# Taille de l'image 

La vitrine est l'interface client d'une boutique en ligne, présentant les produits, les catégories et la navigation pour une expérience d'achat fluide. 

Pour configurer les tailles d'image, accédez au panneau d'administration et cliquez sur **Configurer >> Produits**. 

### Petite image 

Définissez la **Hauteur** et la **Largeur** pour les petites images. 

### Image moyenne 

Définissez la **Hauteur** et la **Largeur** pour les images moyennes. 

### Grande image 

Définissez la **Hauteur** et la **Largeur** pour les grandes images. 

<ImagePopup src="/images/configure/imageSize.png" alt="Image Size Configuration" /> 

Après avoir effectué les modifications, cliquez sur le bouton **Enregistrer la configuration**.
